# Tax Prize Checker v1.0.0

Tax Prize Checker is an Android app that automatically detects Taxpayer Incentive Scheme prize coupon numbers from screenshots and checks them against the prize records published by the Inland Revenue Department (IRD), Nepal.

## Features

* 📷 Select an screenshot from your device
* 🔍 Automatically detect 12-digit prize coupon numbers using OCR
* 🌐 Fetch the latest available prize records from the IRD public API
* 🎟️ Check multiple coupons at once
* 🏆 Display winning coupon details, including prize rank and draw information

## How to Use

1. Open the app.
2. Select an screenshot containing your prize coupon numbers.
3. The app automatically detects the 12-digit coupons.
4. Tap **Check Prize**.
5. View the results and see whether any of your coupons have won.

## Download

Download the APK from release section and install it on your Android device.


## Requirements

* Android device
* Internet connection for checking prize records
